# گزارش آزمون سرور هما

تاریخ: ۲۰۲۶-۱۰-۲۱ — روی Raspberry Pi 3 Model B Rev 1.2 با Debian 13 و Python 3.13.

## نتیجه

- ۱۱ آزمون HTTP، ورود، پنهان‌بودن رمز در پاسخ تنظیمات، اعتبارسنجی، حفظ تاریخچه و جداسازی پیام وضعیت از سنجش دما: موفق.
- آزمون سرتاسری MQTT با ماژول شبیه‌سازی‌شده: ارسال Info، پاسخ، ثبت SQLite، polling، اشتراک فقط هنگام درخواست، جلوگیری از عبور Param بیرونی و عدم ثبت مجدد retained به‌عنوان سنجش: موفق.
- دریافت واقعی یخچال از test.mosquitto.org: موفق؛ قالب و تاپیک قدیمی حفظ شد.
- آزمون restart سرویس: تاریخچه حفظ شد و PRAGMA integrity_check برابر ok بود.
- بررسی درخواست‌های واقعی یخچال: فقط `{"type":"Info"}`؛ هیچ Param یا فرمان تغییر دما ارسال نشد.
- reboot واقعی برد: homa، mosquitto و wayvnc خودکار و فعال؛ API سلامت پاسخ داد.
- بررسی پس از reboot: ۲۰ سنجش واقعی در زمان آزمون، شامل رکوردهای قبل از بوت و سنجش تازهٔ بعد از بوت؛ هر دو بروکر متصل.
- اتصال ناشناس به MQTT محلی: رد شد.
- پایداری نهایی سرویس: ActiveState=active و NRestarts=0؛ RSS حدود ۲۸ مگابایت.
- SHA256 هر چهار فایل اجرایی/وب روی برد با سورس داخل پروژه برابر است.
- پنل در مرورگر داخلی: ورود، نمایش اطلاعات واقعی، بازشدن تنظیمات ماژول، فرم بروکر، پیام‌های زنده، توقف نمایش و خواندن تاریخچه بررسی شدند.
- اطلاعات ورود مالک در دسکتاپ رزبری‌پای و `raspberry-pi/.local/access.txt` در کامپیوتر ذخیره شد؛ فایل از Git خارج است.
- پیش از ارتقای غیرحذفی ساختار سنجش، پشتیبان سازگار SQLite با integrity_check موفق در `/var/backups/homa/homa-20261021T125833647689Z.sqlite3` ایجاد شد.

## حدود آزمون و مرحلهٔ بعد

- مرورگر فیزیکی تبلت Android 4.4 هنوز بررسی نشده؛ رابط با ES5 و XHR پیاده‌سازی شده است.
- انتقال اپ‌های فعلی ویندوز/تبلت به API و توقف polling قبلی آن‌ها در این مرحله انجام نشده است.
- تغییر بروکر در تنظیمات خود ESP، ارسال تنظیم واقعی یخچال، اتصال TLS به بروکر واقعی خارجی، MCP اختصاصی و پشتیبان‌گیری زمان‌بندی‌شدهٔ خارج از کارت آزموده/اجرا نشده‌اند.
- اشتراک بیرونی با کلاینت آزمایشی و پایگاه موقت بررسی شد؛ برای ماژول واقعی یخچال همچنان خاموش است.
- داده‌های اصلی حذف نشدند. پیام‌های وضعیت اولیه به‌صورت غیرحذفی `is_sample=0` علامت خوردند و در لاگ خام و پایگاه داده باقی‌اند.
