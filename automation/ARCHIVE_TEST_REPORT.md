## نتیجهٔ واقعی

- اپ جدید ویندوز و سرور بافر رزبری ساخته و نصب شدند؛ SHA256 فایل server.py نصب‌شده با سورس آمادهٔ استقرار یکسان بود و homa فعال است.
- ۷۶۶ رکورد اولیه از API رزبری به SQLite کامپیوتر منتقل شد؛ ۵۱۴ رکورد قدیمی جدول telemetry بدون حذف باقی ماند.
- دو همگام‌سازی فوری دیگر تعداد آرشیو را افزایش ندادند؛ رکورد تکراری ساخته نشد.
- همگام‌سازی ویندوز قطع شد؛ یک درخواست Info خواندنی از رزبری فرستاده شد و نمونهٔ جدید در بافر با شناسهٔ 769 ثبت شد.
- اپ ویندوز بسته و دوباره اجرا شد؛ نشست ذخیره‌شده بدون ورود مجدد استفاده شد و رکورد زمان توقف به آرشیو رسید: ۷۶۷ رکورد و checkpoint برابر 769. دو شناسهٔ قدیمی پیام وضعیت، سنجش نبودند و در آرشیو سنجش وارد نشده‌اند.
- تطبیق مستقل همهٔ رکوردهای سنجش تا شناسهٔ 769 بین API رزبری و SQLite ویندوز، شامل شناسه، زمان دریافت، ماژول، payload و parsed: SHA256 یکسان `645f719be4cd2373d9eb0c97a733d0d2883c7ba7b20b5e5377aca4a8cad72c8b`.
- `PRAGMA integrity_check` دیتابیس اصلی ویندوز برابر `ok` بود. مقادیر عددی و نام/تنظیمات ماژول هم ذخیره شده‌اند.
- هیچ دما، هیسترسیس، فاصلهٔ نمونه‌برداری یا فریم‌ور واقعی برای آزمون تغییر نکرد؛ فقط یک Info خواندنی ارسال شد.
- پشتیبان قبل از ارتقا: `%APPDATA%\Homa\backups\homa-20261022-021246-010205.sqlite3`.

## آزمون‌های خودکار

- ۱۷ آزمون Python رزبری موفق، شامل محافظت رکوردهای تأییدنشده از پاک‌سازی، صفحه‌بندی و رد ACK بالاتر از عرضه یا منبع اشتباه.
- ۹ آزمون Flutter موفق، شامل ارتقای v1 به v2 با حفظ داده/تنظیمات، View تحلیلی SQL، تراکنش و rollback صفحهٔ خراب، تکرار صفحه بدون تکرار رکورد، دو منبع با شناسهٔ مشابه، شکست ACK و ادامه بعد از اجرای دوبارهٔ ویندوز.
- `flutter analyze`: بدون ایراد؛ ساخت Release موفق.
- تست API روی exe جدید: وضعیت، تاریخچه، پیام‌ها، احراز هویت و تغییر و بازیابی نمودار موفق.

## محدودیت‌ها

اپ باید باز و به رزبری متصل باشد تا آرشیو کامپیوتر به‌روز شود؛ دادهٔ زمان بسته‌بودن اپ در رزبری می‌ماند. اجرای خودکار هنگام ورود به ویندوز هنوز تنظیم نشده است. خرابی فیزیکی کارت/دیسک و حذف دستی داده، بافر نرم‌افزاری را بی‌اثر می‌کند؛ پشتیبان خارج از دستگاه مرحلهٔ نگهداری بعدی است. تبلت هنوز باید جداگانه از polling مستقل به معماری سرور منتقل شود. آزمون تاریخی بروکر ساختگی ویندوز متعلق به معماری مستقیم MQTT است و برای نسخهٔ جدید جای خود را به آزمون آرشیو HTTP داده است.
