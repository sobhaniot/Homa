# Automation

کنترل برنامه‌ای اپ ویندوز از طریق API محلی داخل خود Flutter پیاده شده است. راهنما: `WINDOWS_API.md`؛ کلاینت بدون وابستگی: `homa_control.py`. فقط وقتی اپ باز باشد کار می‌کند و کنترل دسکتاپ لازم ندارد.

Flowهای فعلی Node-RED در پوشهٔ `node-red` نگهداری می‌شوند. Node-RED در معماری نهایی ابزار اتوماسیون و یکپارچه‌سازی است و مسئول احراز هویت یا امنیت اصلی محصول نخواهد بود.
