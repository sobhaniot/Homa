# اپ ویندوزی Homa

## معماری فعلی: آرشیو اصلی کامپیوتر

اپ به API رزبری `192.168.1.55:8080` متصل می‌شود. داده‌های همهٔ ماژول‌ها به SQLite دائمی کامپیوتر منتقل می‌شوند؛ رزبری بافر است و دادهٔ تأییدنشده را حذف نمی‌کند. توضیحات MQTT/تبلت در بخش‌های قدیمی پایین، شرح پیاده‌سازی پیش از مهاجرت هستند و مسیر پیش‌فرض فعلی نیستند. راهنمای معتبر فعلی: `F:\Homa\docs\windows-primary-archive-v1.md`.

## رابط کنترل برنامه‌ای — مرحلهٔ ۱۱

API محلی داخل اپ روی `127.0.0.1:17863` اجرا می‌شود. کنترل همان وضعیت، اتصال، تنظیمات و نمودار اپ بدون کنترل دسکتاپ امکان‌پذیر است. توکن هر اجرا در `%APPDATA%\Homa\control-api.json` ذخیره می‌شود. راهنمای کامل و حدود مرحله در `F:\Homa\automation\WINDOWS_API.md` قرار دارد. API رزبری جداگانه است؛ انتقال سرویس قدیمی این اپ به رزبری و همگام‌سازی آن هنوز مربوط به مراحل بعد است.

اپ Flutter برای اتصال به MQTT و پایش ماژول‌های قدیمی خانه؛ در این برش فقط یخچال پیاده‌سازی شده است.

## اجرای توسعه‌ای

```powershell
flutter pub get
flutter run -d windows
```

برای ساخت نسخهٔ ویندوزی، Flutter و ابزارهای ساخت دسکتاپ ویندوز (Visual Studio با workload مربوط به C++) باید نصب باشند:

```powershell
flutter build windows
```

## قرارداد یخچال قدیمی

- بروکر پیش‌فرض: `test.mosquitto.org:1883`؛
- درخواست‌ها: `/eleknow.com/nahbos5672730/home/refrigerator`؛
- پاسخ‌ها: `/eleknow.com/nahbos5672730/home/refrigeratorResult`؛
- درخواست اطلاعات: `{"type":"Info"}`؛
- تنظیم دما: `{"type":"Param","Temp":9.0,"Hyster":1.0}`.

## ذخیره و همگام‌سازی تاریخچه

- داده‌های زنده و تنظیمات در SQLite ویندوز نگهداری می‌شوند. مسیر پیش‌فرض دیتابیس `%APPDATA%\Homa\homa_telemetry.db` است.
- تاریخچهٔ تبلت از دو topic آزمایشی مستقل دریافت می‌شود:
  - درخواست: `/eleknow.com/nahbos5672730/home/history/request`
  - پاسخ: `/eleknow.com/nahbos5672730/home/history/response`
- اپ ویندوز بعد از اتصال به بروکر بازهٔ ازدست‌رفته را صفحه‌بندی‌شده درخواست می‌کند؛ اولین بار کل آرشیو تبلت گرفته می‌شود و checkpoint صفحه‌ها برای ادامه پس از قطع برنامه حفظ می‌شود. دکمهٔ همگام‌سازی نیز برای تلاش دوباره وجود دارد.
- تبلت باید روشن، برنامه‌اش باز و به همان بروکر متصل باشد. داده‌های تبلت در فایل SQLite خود Android ذخیره می‌شوند.
- نمودار بازه‌های ۱ ساعت، ۲۴ ساعت، ۷ روز و ۳۰ روز را دارد و حداکثر ۶۰۰ نمونهٔ اخیر هر بازه را رسم می‌کند.

## هشدار امنیتی

`test.mosquitto.org:1883` بروکر عمومی و بدون TLS/احراز هویت است؛ topicها و داده‌های آزمایشی می‌توانند برای دیگران قابل مشاهده باشند. از آن برای دادهٔ حساس یا کنترل واقعی تجهیزات پرخطر استفاده نکن. پیش از محصول واقعی باید بروکر خصوصی، TLS، اعتبارنامهٔ یکتا و ACL پیاده‌سازی شود. Firmware قدیمی در این مرحله تغییر نکرده است.
