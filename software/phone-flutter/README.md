# اپ گوشی هما

رابط فارسی شیشه‌ای Flutter با اتصال خودکار به بروکر داخلی و جایگزینی بروکر خارجی در صورت شکست. تنظیمات هر دو بروکر و کارت‌ها قابل‌ویرایش است. برنامهٔ تبلت Android 4.4 در پروژهٔ جداگانه نگه‌داری می‌شود.

راهنمای معتبر معماری، آزمون‌ها و وضعیت خروجی: [مرحلهٔ ۱۹](../../docs/phone-app-v1.md).

آدرس‌های اولیه: داخلی `192.168.1.55:1883` و بیرونی `test.mosquitto.org:1883`. مسیر بیرونی فقط‌خواندنی و برای دادهٔ غیرحساس آزمایشی است.
