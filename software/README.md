# نرم‌افزارهای Homa

- `windows/`: برنامهٔ Flutter ویندوز برای کنترل ماژول‌ها و نمودار تاریخچه.
- `tablet-android/`: برنامهٔ Java تبلت فعلی Samsung GT-N8000 با Android 4.4.2/API 19.
- `phone-flutter/`: برنامهٔ Flutter موبایل؛ مسیر مستقل از برنامهٔ Java تبلت قدیمی است.
- نسخهٔ Cordova در `../archive/cordova/` فقط برای مراجعه و بازیابی نگه‌داری می‌شود و مسیر توسعهٔ جدید نیست.

## وضعیت تاریخچه

برنامهٔ فعلی ویندوز هنوز از سازوکار قدیمی همگام‌سازی با تبلت استفاده می‌کند. در معماری هدف، رزبری‌پای ثبت‌کنندهٔ دائمی تاریخچه خواهد بود و تبلت و ویندوز داده‌ها را از آن می‌خوانند؛ این انتقال هنوز انجام نشده است.

برای ساخت APK تبلت Java، ابزارهای Android/JDK/Gradle در `F:\Homa\tools\android-toolchain` و کش Gradle در `F:\Homa\tools\gradle-user-home` نگه‌داری می‌شوند. پروژهٔ بازیابی‌شدهٔ Cordova در `../archive/cordova-original` است و در ساخت برنامهٔ Java نقشی ندارد.
