# Homa

بستر یکپارچهٔ خانهٔ هوشمند برای کنترل و پایش ماژول‌های ESP از طریق MQTT.

مخزن خصوصی کد: [sobhaniot/Homa](https://github.com/sobhaniot/Homa). محدودهٔ فایل‌های ثبت‌شده و روش آماده‌سازی اسکچ‌های بدون رمز در [راهنمای مخزن](docs/repository.md) آمده است.

## نقشهٔ پروژه

```text
Homa/
├── software/
│   ├── windows/          برنامهٔ Flutter ویندوز
│   ├── tablet-android/   برنامهٔ Java سازگار با تبلت Android 4.4
│   └── phone-flutter/    برنامهٔ Flutter برای گوشی
├── arduino/
│   ├── modules/          فریم‌ور ماژول‌های قدیمی ESP/Arduino
│   ├── libraries/        کتابخانه‌های مشترک ماژول‌ها
│   └── legacy-sketches/  اسکچ‌های قدیمیِ دسته‌بندی‌نشده
├── raspberry-pi/         سرور محلی، پنل وب، API و آزمون‌های رزبری‌پای
├── automation/node-red/  فلوهای Node-RED
├── tools/                اسکریپت‌های پروژه و پیوند ابزارهای مشترک
├── docs/                 پروتکل و مستندات پروژه
├── archive/              نسخه‌های قدیمی، از جمله Cordova
└── PROJECT_RULES.md      قوانین پروژه
```

نسخه‌های قدیمی Cordova و ابزارهای جانبی که هنوز برای ساخت تبلت لازم‌اند در
`archive/` و `tools/` نگه‌داری شده‌اند؛ پوشه‌های پراکندهٔ قبلی دیگر محل فعال پروژه نیستند.

## معماری و وضعیت

وضعیت جدید مرحلهٔ ۱۹: اپ گوشی Flutter با رابط فارسی شیشه‌ای و اتصال «بروکر داخلی ← خارجی» در `software/phone-flutter` توسعه یافته است. قرارداد کش MQTT، نتایج آزمون و محدودیت‌ها در [راهنمای اپ گوشی](docs/phone-app-v1.md) ثبت شده‌اند. توضیحات زیر دربارهٔ انتقال اولیهٔ رزبری و همگام‌سازی تبلت تاریخی‌اند؛ معماری فعلی، رزبری به‌عنوان بافر و دیتابیس اصلی روی درایو F کامپیوتر است.

ماژول‌های قدیمی حفظ می‌شوند و فعلاً قالب پیام و تاپیک‌هایشان تغییر نمی‌کند. هدف مرحلهٔ بعد، انتقال بروکر MQTT و ثبت دائمی تاریخچه به رزبری‌پای در شبکهٔ خانه است. برنامهٔ ویندوز باید تاریخچه را از رزبری‌پای بگیرد و تبلت نقش نمایشگر و کنترلر داشته باشد؛ تبلت دیگر مرجع اصلی تاریخچه نیست.

سرور رزبری‌پای با پنل فارسی، بروکر محلی رمزدار، ثبت SQLite، API تاریخچه و دریافت دوره‌ای مستقل ماژول‌ها پیاده‌سازی شده است؛ راهنما در `raspberry-pi/README.md` است. پنل فعلی روی `http://192.168.1.12:8080` قرار دارد. یخچال تا انتقال تنظیم بروکرش همچنان از بروکر خارجی خوانده می‌شود.

برنامهٔ فعلی ویندوز همچنان نسخهٔ قبلی همگام‌سازی با تبلت و ذخیرهٔ محلی SQLite را دارد؛ اتصال ویندوز و تبلت به API جدید و حذف polling قبلی آن‌ها مرحلهٔ بعد است. اتصال به بروکر عمومی Mosquitto فقط برای آزمایش است و اشتراک بیرونی سرور برای هر ماژول پیش‌فرض خاموش است.

ابزارهای مشترک توسعه در `F:\_DevTools` قرار دارند؛ پوشهٔ اصلی پروژه `F:\Homa` است.
